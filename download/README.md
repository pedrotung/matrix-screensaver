# Download / 下载

## English

**`MatrixRain-windows.zip`** is the ready-to-use screensaver for **Windows 10 / 11**. Click the file name above, then click the **Download raw file** button (↓) on the right. You can also get it from the [latest release](https://github.com/pedrotung/matrix-screensaver/releases/latest).

1. Unzip it and move `MatrixRain.scr` to a folder you will keep.
2. Right-click `MatrixRain.scr` and choose **Install**.
3. In *Screen Saver Settings*, click **Settings** to change speed, density, font size and the exit password.
4. If Windows shows "Windows protected your PC", click **More info**, then **Run anyway**. This appears because the program is not code-signed.

The zip contains `MatrixRain.scr`, `README-en.md` (English guide) and `使用说明.md` (Chinese guide).

## 中文

**`MatrixRain-windows.zip`** 是可以直接使用的 **Windows 10 / 11** 屏保。点上面的文件名，再点右侧的下载按钮（↓）即可下载。也可以到 [Releases 页面](https://github.com/pedrotung/matrix-screensaver/releases/latest) 下载。

1. 解压后把 `MatrixRain.scr` 放到一个固定的文件夹。
2. 右键 `MatrixRain.scr`，选择「安装」。
3. 在「屏幕保护程序设置」里点「设置」，调整速度、密度、字号和退出密码。
4. 如果出现「Windows 已保护你的电脑」，点「更多信息」再点「仍要运行」。这是因为程序没有数字签名。

压缩包里有 `MatrixRain.scr`、`README-en.md`（英文说明）和 `使用说明.md`（中文说明）。
